# Чекліст для Code Review

Перед тим як перевести Pull Request у статус Ready for Review або зробити Approve, перевір наступне:

- [ ] **Scope:** PR містить лише зміни, які стосуються цього тікета (немає зайвих файлів).
- [ ] **Linear:** В описі PR є посилання на тікет у Linear, а сам тікет знаходиться у статусі "In Progress" або "In Review".
- [ ] **Commit History:** Історія комітів читабельна, назви комітів відповідають конвенції (наприклад, Conventional Commits).
- [ ] **Запуск:** Код успішно запускається локально без помилок.
- [ ] **Помилкові сценарії:** Опрацьовані потенційні помилки та edge-кейси (крайові випадки).
- [ ] **Скріншоти:** Якщо змінено UI, в PR додано скріншоти "До/Після".
