# Stakeholder Directory Mini-Project

Міні-проєкт поєднує 3 попередні модулі в один інтерфейс.

---

## 🚀 Функціонал (Features)

1. **Client-side CRUD**:
   - **Create**: створення нового стейкхолдера через форму з валідацією.
   - **Read**: завантаження та табличне відображення записів з асинхронного Mock API.
   - **Update**: редагування існуючого запису з попереднім заповненням форми та збереженням змін.
   - **Delete**: видалення стейкхолдера з обов'язковим підтвердженням дії (`window.confirm`).

2. **Комбінований пошук і фільтрація**:
   - Пошук за підрядком в **імені** або **організації**.
   - Фільтрація за **роллю** (All / вибір ролі).
   - Фільтрація за **рівнем впливу** (All / 1–5).
   - Усі фільтри працюють одночасно й перераховують лічильник знайдених записів.

3. **Керування станами інтерфейсу**:
   - **Loading State**: індикатор завантаження під час виконання асинхронних запитів.
   - **Error State**: блок повідомлення про помилку з можливістю повторного запиту (**Retry**).
   - **Simulate Error**: тестова кнопка `Simulate next error` для виклику керованого збою наступного запиту.
   - **Validation State**: перевірка обов'язкових полів (`name`, `email`, `role`, `organization`, `influence`), валідація формату email (наявність `@`) та підсвічування помилок.
   - **Empty State**: інформаційне повідомлення, коли фільтри не повернули жодного результату або список порожній.
