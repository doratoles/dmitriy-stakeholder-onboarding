## Мета онбордингу
Цей репозиторій призначено для підготовки до першої реальної задачі у Stakeholder через послідовні практичні модулі з Git, 
TypeScript, React, Laravel та Inertia.

## Призначення apps/
Містить основний робочий код проєкту, що включає в себе бекенд та фронтенд рішення, які можуть бути інтегровані між собою.

## Призначення exercises/
Простір для практичних завдань та інтерактивних вправ. Створений спеціально для процесу онбордингу. 
Тут знаходяться тестові та тренувальні завдання, які допоможуть розібратися з бізнес-логікою, архітектурними паттернами
та інструментами, що використовуються в реальних задачах.

## Призначення docs/
Центральна база знань проєкту. Тут зібрана вся необхідна технічна та процесна документація.
